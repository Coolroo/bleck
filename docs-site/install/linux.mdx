title: Linux
description: Installing bleck on Linux
---

<Steps>
  <Step title="Install uv">
    ```bash
    curl -LsSf https://astral.sh/uv/install.sh | sh
    ```

    Or use pip if you prefer — see [the alternative](#without-uv) below.
  </Step>

  <Step title="Install the external tools">
    ```bash
    sudo apt install -y wit dolphin-emu
    ```

    On Debian and Ubuntu, `dolphin-tool` lands in `/usr/games`, which is not
    always on PATH. `bleck` looks there anyway.
  </Step>

  <Step title="Clone and sync">
    ```bash
    git clone git@github.com:Coolroo/bleck.git
    cd bleck
    uv sync --extra dev
    ```
  </Step>

  <Step title="Verify">
    ```bash
    uv run pytest          # expect 145 passed
    uv run bleck --help
    ```
  </Step>
</Steps>

## Without uv

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

Both workflows are supported. With a venv active, drop the `uv run` prefix from
every command.

## ARM64 and Raspberry Pi

`bleck` runs on aarch64 — it was developed on a Raspberry Pi 4.

<Warning>
Dolphin will *boot* a Wii game on a Pi 4, but far too slowly to reach the title
screen in reasonable time. Use a desktop for visual testing. See
[Testing](/guides/testing).
</Warning>
